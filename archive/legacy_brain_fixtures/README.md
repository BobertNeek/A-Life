# Legacy brain fixtures

This directory preserves test assets tied to retired neural layouts.

- `p32_tiny_initial_weights_v1.json` encodes the old 17-lobe topology and its
  original hashes. Current v2 code must not import it as a valid nine-lobe
  foundation asset.

Use Git history for the test that consumed this fixture. Generate a new,
source-bound fixture if current P32 import coverage needs a committed asset.
