# Legacy Pass 2 runners

This directory preserves standalone Pass 2 population and EI1 PowerShell runners plus their exclusive schemas. No active workflow, crate, package, or supported command calls them.

The active `pass2_fast_gates.ps1`, EI1 scenario catalog, and experiment manifest schema remain under `scripts/` because current workflow and Rust code still consume them.

These archived files retain their historical paths and defaults as evidence. They are not supported launch or validation entrypoints.
