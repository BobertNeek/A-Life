# Terrain care N2048 founder revision

Explicit unpromoted revision of `terrain-care-n2048-v1` for the current inherited
founder decoder. `founder-refresh.json` records both asset and decoder identities,
and exact compiler reconstruction. All 32,768 trained weight bits, neuron
addresses, and synapse coordinates are preserved. The revision adds inherited
survival salience; it is not new learned navigation or speech acceptance.

Generate with `train_n2048_care --refresh-terrain-founder SOURCE NEW_DIRECTORY`.
Fresh training uses the accompanying `adaptation.json`; optimizer and value state
reset. Source assets and saved creatures are retained. Exact candidate admission
still binds decoder genes, so this does not qualify arbitrary descendant variation.
