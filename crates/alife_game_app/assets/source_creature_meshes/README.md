# Licensed Creature Mesh Sources

This directory retains whole-animal OBJ authoring references from the former
procedural part slicer. The current game ships the Hearthling GLB; these sources
are outside the runtime package.

The meshes are derived from **Quirky Series - FREE Animals** by **Omabuarts
Studio** under Creative Commons Attribution 4.0 International (`CC-BY-4.0`).
