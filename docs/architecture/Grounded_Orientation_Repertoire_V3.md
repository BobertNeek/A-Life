# Opt-in grounded orientation repertoire V3

`CognitiveArchitectureGenomeParameters::with_grounded_orientation_v3(heads)` is a fresh-genome opt-in. V3 retains the V2 independent Locomotion / Orientation / Manipulation / Vocal / Posture prefix, with the existing one-to-five-head and compiled-width bounds. V1 and V2 genomes retain their existing constructors, wire versions, motor layouts and candidate repertoires. No production foundation asset is replaced. Old readers reject V3 architecture rather than reinterpret it as V1/V2.

For GroundedObjectSlotsV1 only, World reads the immutable registered organism's expressed genetic architecture and admits the existing STEP_FORWARD, TURN_LEFT, TURN_RIGHT, LOOK_LEFT, LOOK_RIGHT, LOOK_CENTER and HOLD_GAZE primitives. These are ordinary unscored physical opportunities, not forced actions or a policy. The opt-in does not add terrain vision, nutrition, object-kind labels, memory lanes or other sensory features. Existing neural weights and decoder coordinates remain applicable; actual usefulness requires fresh behavioral evaluation.

Public legacy enumerators remain unchanged. The explicit V3 enumerator and frame constructor validate V3 parameters. World owns the organism binding; possession of an arbitrary architecture value outside World is not proof of organism ownership. Optional typed frame provenance is bound into its digest and preserved by attention/focus and semantic rebuilds. Old frames omit that field and keep their original digest stream. CPU and GPU share the World/runtime preparation route; GPU uses the existing V2 channel-layout marker because the channel policy is identical, not because V3 is silently reclassified as a V2 genome.

## Fixed candidate budget and clutter

The frozen foundation limit remains 32 candidates. V3 reserves space for seven primitive opportunities and therefore admits at most three observed object slots rather than the legacy grounded profile's four. Each object still receives the same six action opportunities. Current calibrated contact and focal object reservation use the existing deterministic rules: contact is retained when focus competes, and neither an unobserved target nor a non-contact nomination can enter through this path. This is a real clutter tradeoff, not a hidden food selector. Changing architecture can change the visible action set and subsequent learning even with identical inherited weights.

## State and evidence boundaries

Genetic opt-in changes phenotype identity. It is not a migration of an acquired individual, and existing checkpoints must not be patched to claim the new phenotype. Native tests exercise sampled actions through normal World execution; deterministic candidate-construction tests establish bounds/identity, not learned gaze skill. CPU qualification is not GPU execution or FPS evidence. No memory-cap, reward-credit, learner, or neural-reset change is included.
