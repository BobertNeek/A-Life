# Era 1 Norn-plus Evidence Lock

Status: implemented program with source-bound acceptance evidence.

Era 1 keeps the production N2048 brain class and GPU-authoritative closed loop.
It adds eleven behavioral abilities, four named causal disabled controls, held-out
world transforms, ordinary-birth provenance, and bounded multi-lineage evolution.
Teachers expose perception-only lessons. They do not inject actions, meanings,
rewards, answers, policy state, or hidden promotion evidence.

Run the evidence lock from a clean committed source state:

```powershell
cargo run -p alife_tools --bin era1_promotion -- --out crates/alife_tools/reports/era1_promotion_report.json
```

The report binds its Git commit, tree, source-contract blobs, RTX 3050 adapter,
Vulkan API, authoritative evolution receipt, real GPU trial receipts, costs,
and the inherited Era 0 portable-save and archive receipts. Full causal trial
traces live in the digest-bound `era1_trial_evidence.jsonl.zst` sidecar. The
validator streams every trace, recomputes every receipt, then recomputes the
evolution, promotion, plateau, matrix coverage, and all listed digests. Missing
trial cells and plateau windows remain `UNKNOWN`; they never become zero scores
or synthetic receipts.

`PASS` requires all 2,640 descendant ability/control receipts: 1,320 from each
of ordinary-birth generations 1 and 2. Generation 1 evidence is shared with its
selection round without relabelling; founder selection evidence is excluded. A
smaller real run produces `BLOCKED`, while still proving the tested GPU path.
Neither verdict authorizes a larger brain class. Era 2 remains `OUT_OF_SCOPE`.

This changes evidence orchestration and documentation only. It does not change
an authority boundary, so no new ADR is required.
