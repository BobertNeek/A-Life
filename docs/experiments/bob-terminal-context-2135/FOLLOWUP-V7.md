# V7: diagnostic-only research row boundary

`CpuCollectedDecision` retains its in-memory fields and ordinary derived deserializer. Its custom serializer uses a private borrowed flat payload with exactly the original field order and optional omissions. Default-off rows serialize identically. No arrays are cloned, no fields are dropped, and no actions, logits, learning or Core ABI are changed.

When `terminal_context2135` is present, serialization produces a single-key object `terminal_context2135_research_record_v1` containing the complete flat row. This includes enabled ZeroHead, masked, denied-budget and tiny-delta rows: presence, not magnitude, selects the boundary. Both old and current ordinary flat-row deserializers reject this envelope because required top-level fields such as `organism_id` are absent. Existing current in-memory cohort rejection remains intact. Research records are diagnostic-only until a versioned trainer explicitly supports them.

Enabled generic row serialization/deserialization roundtrip is intentionally unsupported. Full canonical host checkpoints, with V5's schema 3 head-preservation boundary, remain the restore path. This patch does not alter checkpoints or promise migration of already emitted unwrapped prototype research rows. Preserve old raw data and do not admit it to an ordinary trainer by stripping fields or unwrapping the diagnostic payload.

Two bounded serializer component tests passed under Rust edition 2021 with strict Clippy. They check a borrowed projection's exact default-off bytes, field order and Option omission, complete nested enabled bytes, old/current ordinary reader projection rejection for zero/tiny/nonzero deltas, and input immutability. These are serializer projections, not full native-row or trainer admission tests. Full host compile and native full-row checks remain remote gates, as do informative learned behavior and cold-state qualification. No Cargo or World runs were performed. V1 through V6 remain unchanged. Raw records stay LOCAL and outside publication.
