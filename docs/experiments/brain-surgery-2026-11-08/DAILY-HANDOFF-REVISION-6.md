## GPU durability is separate and still being implemented

A phase tag is insufficient to make post-arousal neural writes durable. The
compact journal reuses older exact assets; refreshing its in-memory authority
does not publish a new neural epoch. An already active old checkpoint worker
also does not prove a new aroused decision was captured.

GPU save validation correctly binds a committed sleep output generation to its
active neural generation. A legitimate later aroused decision can change that
generation while the unfinished cycle retains its original commit receipt.
The next factor therefore needs explicit historical-commit plus new-epoch
lineage, real immutable capture/publication identity, Completed-permit handling
and interruption-aware dispatch/recovery gates. It must not rewrite the old
receipt or weaken equality to cycle IDs. GPU activation stays off while those
boundaries are qualified. CPU v7 is not live-GPU transaction or gameplay evidence.

A separate body-only kernel has been extracted onto ordinary main and passed
582 world tests plus strict Clippy, but publication was held after review found
two missing physical cases: outward escape from an initially overlapping peer,
and an own-carried harmful object misclassified as an unrelated external blocker.
Both now fail in native prerepair tests on the unchanged kernel; three negative
entry/grip controls pass. The narrow repair and full requalification are in progress. This extracted opt-in API does not
activate normal gameplay or change cognitive state. No old passing suite is
relabeled as having covered those newly found cases.

## Thermal and reproductive physiology: actual tests and interface limits

The [source audit and two disposable core tests](thermal-reproductive-audit/AUDIT.md)
run on ordinary-main-equivalent tree 0a34d588. Both tests pass. Supplied thermal
exposure reaches body/chemistry; recovery lowers body load 0.495→0.29500002.
Live ATP 0.249 blocks reproductive readiness and 0.25 admits it, alongside puberty,
health, opportunity, compatibility and energy gates.

These are actual core fixtures, not ordinary-world thermal exposure or autonomous
mate seeking. Existing surface-temperature descriptors are randomly initialized
signed values, even on food and peers. Ordinary world physics does not translate
them into physiological thermal exposure. Turning their absolute magnitude into
harm would make arbitrary objects hazardous. A separate opt-in contact/thermal-
balance prototype is under development, with explicitly configured conductance,
neutral band, interval dose, tolerance and relief. It does not change random
ordinary descriptors or introduce a hidden refuge choice.

The prototype also exposed an inherited-model tension: sleep cooling can exceed
its modest continuous external heat dose. The first factor will retain/document
that result; a distinct follow-up thermal-balance factor can test suppression of
only sleep's thermal subtraction during configured exposure, while retaining
fatigue/ATP/metabolic benefits. No thermal prototype qualification is inferred
from the two core tests archived here.

Reproduction is proximity/readiness physiology under the current design, not an
explicit Mate action or verified motivated neural policy. No controlling
requirement for a new refractory timer was found, so the audit does not silently
change ordinary reproduction. Missing grounded consequences and affordances
cannot be repaired merely by increasing a decoder weight.

pending. Eight rows are appended: 96→104. Active

The first frozen synthetic factorial is not a strong-policy result. A readout-only
