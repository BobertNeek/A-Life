# Experimental founder admission prototype

`bold-game-admission.patch` prototypes a separate `n2048-experimental:<asset-path>` fresh-founder choice. It uses the existing experimental new-game constructor and selects the experimental compiler in the GPU live runtime when the saved candidate identifies itself as experimental. The ordinary `n2048:` choice remains separate; existing lives are not converted.

At current-main c3aec16, `cargo check -p alife_game_app --features gpu-runtime` and the corresponding `--tests` check completed on the cloud CPU environment. A check compiles code and test targets but does not execute tests or run a GPU. The full Bevy frontend and GPU-runtime cargo check also passed after supplying local pkg-config metadata for the system runtime libraries; this was a compile check, not a game launch. Executed CPU-side unit tests passed for explicit selection parsing, experimental new-game staging/save/reload with exact recovered weight bits, and the existing standard-founder staging/save/reload. No GPU dispatch, full game launch, live GPU state save/load, or gameplay has been verified. This patch is a prototype, not merged into the game. Validate the asset identity and all relevant GPU, save/load and gameplay paths before admission or promotion.
