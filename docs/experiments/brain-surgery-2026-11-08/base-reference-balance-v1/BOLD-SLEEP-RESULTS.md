# Combined-brain sleep-retention pilot

Apply `bold-sleep-probe.patch` after `bold-combined.patch`, followed by `bold-cue-sleep.patch`. The optional switches apply only to disposable research founders.

One fresh candidate was deliberately put through forced recovery sleep after 16 decision steps. It consolidated, woke and resumed after 14 intervals. The consolidation changed 26,088 lifetime entries; the next step after checkpoint restoration exactly matched the uninterrupted continuation. This establishes state transition and restoration in that case, not that every changed entry is useful.

A second pilot forced sleep after the same four safe/harm cue exposures and before presenting the choice. With harmful exposure first, two seeds, both safe colors and both object creation orders (one side arrangement), the creature chose the safe cue 8/8 times. Each run reported sleep/wake completion and exact cold next-step continuation. This is a small, controlled CPU result. It does not isolate synaptic plasticity from episodic memory, establish generalization or validate GPU/game behavior. No saved user life was touched.
