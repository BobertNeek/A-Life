# Decoder eligibility timing ablation

The diagnostic trace suggests old cue eligibility carries into subsequent painful food experiences. Test causality, not a proposed production fix: in a research-only local CPU binary, `ALIFE_RESEARCH_DECODER_TRACE_RESET=1` replaces each ActionCandidate decoder's decayed prior eligibility with only the current decision's local contribution. The old decayed term is still computed; recurrent, memory and other eligibility are unchanged. This removes action-decoder multi-decision temporal credit and could break genuinely delayed consequences. It is not an instruction to remove eligibility traces in the game; do not merge the environment switch or promote on this immediate-outcome test.

First check the same binary with the switch absent against two previously traced seed-1551 cases (red-safe, red-left, safe-first and harm-first), including exposure history, sampled actions and physical outcomes; the default path must match exactly. Then, if that check passes, compare reset vs the previously frozen baseline/sham matrix over the same two exploratory seeds 2026111551–1552 × safe color × side × exposure order × normal/sham = 32 reset trials. These are design-set diagnostic repeats, not held-out proof. All actual exposure and pain receipts, action-choice, eligibility and fast changes, censored cases, cold/optimizer checks and pairwise normal/sham comparisons must be retained. If reset appears promising, follow with fresh-seed, longer-delay consequences and behavior/sleep retention controls before considering a biologically compatible targeted tuning.

Source is current main c3aec16 + cue-study.patch, cue-trace.patch, cue-decompose.patch, cue-approach70.patch, cue-matrix.patch, cue-credit-trace.patch and `cue-decoder-reset.patch`, with the two pinned example support files in CURRENT-MAIN-PLAN.md. No user's saved brain/default is touched; CPU only. Sham and decoder-reset are independent research-only switches and must never be merged into gameplay as environment flags.
