# Decoder eligibility reset: carryover reduced, behavior unchanged

The local CPU research ablation reset only ActionCandidate decoder eligibility to the current decision's local contribution; recurrent and other eligibility remained unchanged. This was a diagnostic intervention, not a biologically complete learning rule or an accepted product change. It removes multi-decision decoder credit, which may harm delayed consequences; no delayed-credit test was run. The research-only environment switch must not be merged into gameplay.

First, the modified binary with the switch absent exactly reproduced the two previously traced seed-1551 safe-first/harm-first cases: exposure histories, probe action/target/contact traces, choices, fast-change counts and cold checks matched. With reset enabled, all 32 predeclared design-set trials completed (two reused seeds, safe color × side × order × normal/sham). All genuine exposures and pain outcomes, and all probe sampled action/target/contact traces, matched the corresponding baseline cases. Each mode chose the previously safe cue 4/16 and previously harmful cue 12/16, exactly as before. Normal and sham choices matched in all 16 reset pairs. All 32 reset flags, exact cold-next-step and unchanged-founder-optimizer checks were true; normal fast values changed and sham fast values stayed unchanged.

The intervention did reduce the measured color trace carryover: in seed 1551 safe-first at the first harmful blue event, mean Ingest eligibility for prior safe red fell from about -0.28733 (baseline) to -0.02023 (reset), while current harmful blue went from -0.38378 to -0.18209. Despite that change, the same sampled choices persisted, and the first-probe safe-minus-harmful score difference remained tiny and order-dependent. Thus carryover is real, but clearing these decoder traces alone did not improve the measured choice outcome. It does not rule out a contribution in other tasks or prove a specific alternative learning mechanism. Do not erase eligibility traces globally or simply amplify the existing signal.

`cue-reset-summary.json` contains all outcomes, exposure records and full-trace hashes; the unmodified-binary two-case equivalence was checked separately. No user life, default asset, production runtime, trained checkpoint or GPU path was changed. Future work should inspect receptor/activation sign and outcome credit, test delayed consequences, and validate any candidate against retained learning rather than treating this failed ablation as a fix.
