# Where the small cue-score difference comes from

Four read-only diagnostic reruns of previously used seed 2026111551, red-safe/red-left, safe-first/harm-first and normal/sham. All training exposures, probe sampled action/target/contact sequences and choices exactly matched the frozen matrix. The actual Ingest logits were reconstructed exactly in the captured first probe decision from family/innate bias + ActionCandidate sum + clamped MemoryContext sum + clamped CognitiveContext sum. This is a replay of the same already-observed decisions, not new independent behavioral evidence.

For safe-first normal, red (safe) minus blue (previously harmful) Ingest score was +0.0016012: ActionCandidate contributed about +0.0000076 of the difference and MemoryContext about +0.0015936. For harm-first normal, safe-minus-harmful was -0.0002995: ActionCandidate about +0.0000134 and MemoryContext about -0.0003126. The cognitive and bias terms were zero in these samples, and memory raw values were within the ±0.5 clamp. With fast writes suppressed, both cues had equal Ingest scores and the MemoryContext weights contributed zero, even though captured memory input lanes were present. Normal and sham made the same physical choices. Thus the tiny order-dependent differential in these observed cases is predominantly a memory-readout effect, not direct color-lane action weights; it is not reliably safe-directed or large enough to establish a learned behavioral preference.

`cue-head-summary.json` preserves the component terms, decoder inputs and trace hashes. No host state, production code, user life, default brain or GPU path was modified. Next inspect how episodic outcome signals reach memory features and their credit, and evaluate any targeted repair against counterbalanced cues and delayed outcomes; do not simply amplify an order-dependent signal.
