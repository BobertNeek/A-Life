# Remembered-pain readout: exploratory pilot

The candidate writes an aggregate -4.0 into 48 previously zero Ingest MemoryContext decoder weights on lane 26, evenly (-0.0833333 each), in addition to the two Approach70 genetic edits. Lane 26 is the target's recalled pain-drive delta weighted by retrieval confidence. This uses existing episodic memory and decoder structures; no new gene, action script or memory system is added. It is a fresh research founder, not a change to a user's saved creature. The 48 weights are authored inherited values, not 48 learned weights.

Four design-set CPU trials repeated seed 2026111551, red safe/red left, safe-first/harm-first × normal/sham. All four real exposures were consumed in every run; safe pain was 0 and harmful pain about 0.240/0.232. At the first two-food test decision, remembered-pain readout lowered the formerly harmful blue Ingest score relative to red by about 0.30–0.33, with the observed memory term within the ±0.5 clamp. Both normal and fast-write sham exhibited the shift because both still possess episodic memory and authored memory weights. Nevertheless both chose blue in safe-first and red in harm-first, exactly the same physical choices as the prior baseline; this pilot does not show improved behavior or a learned preference. All four cold-next and founder-optimizer checks passed; normal fast entries changed, sham did not.

This is a single reused seed/mapping that informed the candidate, not a successful learning study. The memory-value cue might be correlated with experience, but a real test requires fresh seeds, counterbalanced safe colors/side/order, matched normal/sham controls and a matched history with unrelated cue colors; the latter helps distinguish stimulus-specific experience from general pain, recency or position bias. Safety checks must also include unrelated pain and ordinary food seeking, since global avoidance can harm survival. `cue-memory-pain-summary.json` contains exact 48 edits, outcome and first-probe score terms with full-receipt hashes. No default, GPU path, production flag, trained checkpoint or user life was changed.
