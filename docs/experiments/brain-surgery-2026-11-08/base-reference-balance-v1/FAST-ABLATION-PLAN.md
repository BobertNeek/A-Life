# Fast-weight causal probe, pilot

The preceding 16 CPU runs showed fast-state changes but did not establish that they affect behavior. On a fresh current-main c3aec16 experimental founder, run the ordinary host for 16 decisions. Clone the complete resulting checkpoint and replace only the clone's individual fast offsets with their pre-experience values; preserve its current activity, eligibility, world, chemistry, memory, RNG and all other fields. Restore the clone, compare its next decision and replay logits with an unmodified clone from the same checkpoint, and assert the same pre-action perception and candidate count. This is a one-boundary counterfactual surgical ablation, not a production migration or a no-learning lifetime control. The original host and any user-saved life are never changed. Different logits would demonstrate a direct immediate policy effect from the fast state, not a useful learned skill; unchanged outputs or restore rejection are legitimate outcomes.

Pilot seed 2026111538, food and far-food, original and two-weight boost: four 16-decision CPU runs. Log only scalar changes and digests, no full neural arrays. If the host rejects the modified checkpoint or a comparison invalidates assumptions, preserve failure and investigate; do not weaken integrity checks. After a valid pilot, larger matched seeds and novel-context behavioral controls remain needed.
