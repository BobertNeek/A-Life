# Detached fast-offset replay: one-seed pilot

Current main c3aec16 plus `fast-replay.patch` and the pinned example support files. After the earlier host checkpoint intervention was correctly rejected (see FAST-ABLATION-FAILED.md), this experiment leaves the real host and its authority guard unchanged. It evaluates a captured next-decision replay twice with identical pre-decision activation, perception and context. In the modified detached copy only, the fast component of each effective weight offset is returned to its initial value; the current lifetime component is retained. Before modifying the copy, each observed offset was verified bit-for-bit against the sealed actual state's lifetime + alpha × fast. No counterfactual action is executed in the world.

The prospective pilot completed four CPU trials: one fresh seed 2026111539, near and far food, original and two-weight boosted experimental founders, 16 prior decisions. Maximum candidate-logit differences after removing the fast contribution were 0.00268233 for near food in both arms, 0.00104904 for far food original, and 0.00388718 for far food boosted. Every offset-binding check and all four exact cold-next-step/optimizer checks passed. These numbers demonstrate immediate numerical policy-score sensitivity to the accumulated fast state under these four captured contexts. They do not demonstrate a change in a sampled decision, improved physical behavior, an acquired useful skill, long-term persistence or general performance. Food near the creature had already been consumed in these pilot cases; the next decision is not an independent food-choice learning test.

The original host, its authority checks, current game default and all user lives remain unchanged. `fast-replay-summary.json` records candidate identities, fast-change counts, exact replay score vectors and full-receipt hashes. No full private weights are uploaded. Further matched exposure, negative controls and a novel-cue behavioral comparison are required before calling this useful learning; the frozen boost remains unpromoted and no GPU result is claimed.
