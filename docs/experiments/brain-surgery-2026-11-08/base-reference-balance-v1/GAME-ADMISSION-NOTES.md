# Fresh experimental-founder game admission: current code boundary

Inspection at main c3aec16, not a runtime or GPU test. The candidate evaluated in these notes is an opt-in N2048 experimental graph with its own phenotype, route, plasticity and persistent-address identities. Existing focused tests verify it cannot be admitted as the ordinary N2048 foundation and that CPU checkpoints reject crossing that graph boundary. Do not reinterpret an existing creature's learned arrays as this graph.

Current `crates/alife_world/src/new_game.rs` provides `create_canonical_new_game_with_n2048_experimental_candidate` for an explicit fresh experimental asset, and binds the asset to the new genome. In contrast, `crates/alife_game_app/src/new_game_lifecycle.rs::stage_phase3_new_game_with_founder` routes its current `N2048Candidate` selection through `create_canonical_new_game_with_n2048_candidate`, which rejects experimental assets. Separately, `crates/alife_game_app/src/gpu_live_runtime.rs` handles a genome's N2048 foundation candidate through `PhenotypeCompiler::compile_n2048_foundation_candidate`, the standard-graph compiler, not the experimental compiler. Thus the CPU experimental results cannot simply be made playable by pointing the current standard N2048 selection at the candidate file.

A potential future implementation is a clearly opt-in fresh-founder selection with explicit experimental asset validation and matching GPU admission through `compile_n2048_experimental_foundation_candidate`; preserve all ordinary selection and old save behavior. This is a design direction, not an implemented or validated bridge. It also requires exact GPU execution, numerical parity, save/load and live gameplay tests on supported hardware; merely dispatching a different compiler is not evidence that every downstream archive, reproduction, rendering or migration path works. Existing lives retain their own graph and acquired state; no automatic cross-graph conversion is justified by the current tests. Candidate behavior and learned-memory safety are still under study.
