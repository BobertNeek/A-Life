# Neutral-food screening for a later cue-learning task

Before assuming the existing brain can learn a cue-outcome association, verify that a fresh creature will actually interact with a nutritious food whose raw primary chemical cue is neutral (0.0), not the already hard-coded positive +0.85 cue. This is a single food object within reach, nutrition 0.6, no hazard; no extra neural circuit or forced action. Initial body energy is 0.4, but newborn hunger must be reported from the actual receipt rather than assumed. This screening alone is not an association-learning test.

Current main c3aec16 plus `neutral-food-sham.patch` and two pinned example-only support files; the patch includes the isolated research-only fast-write sham, never for game runtime. Four new seeds 2026111542–1545 × original/boost × normal/sham = 16 fresh CPU trials, 64 decisions. Compare first physical consumption or no consumption, actual sampled actions, fast/eligibility changes and exact cold-next-step/optimizer checks. Both modes execute the candidate update calculation; sham skips its fast write, but no equal-time claim is made and other memory/predictor mechanisms remain active. If no neutral food is eaten, do not design a supposed learned color preference on fictitious exposures; diagnose the base action first. If consumption occurs, a later two-cue/reversal experiment must have real outcomes and matched controls. No user life or default asset is changed.
