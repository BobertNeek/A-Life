# Actual per-organism neural state changes

Main c3aec16df33861f1316d127736f5f60eea327ede plus `somatic-observe.patch` and the two pinned example-only support files in `CURRENT-MAIN-PLAN.md`. The patch adds a read-only initial/final checkpoint comparison; it does not write to neural state. It counts bitwise-changed individual fast, lifetime and eligibility entries by synapse kind and maximum absolute delta, without uploading the arrays. Native CPU, opt-in experimental graph, fresh authored founders; no current game default or user-owned retained life was modified.

The prospective matrix completed 16 trials: seeds 2026111534–1537, near and far food, original and two-weight boost, 64 decisions. In every trial, 26,624 fast-weight entries differed from the initial state: 24,576 recurrent and 2,048 decoder entries. Maximum individual absolute fast delta per trial ranged from 0.00047534 to 0.00061810. Eligibility also changed in 26,624 entries; no lifetime entries changed over these runs. Weight generation advanced from 0 to 64. All 16 reports show exact serialized cold-next-step continuation and unchanged founder optimizer. This is evidence of individual fast-state plastic updates, not evidence that behavior improved because of those updates; no equal-work learning-disabled control or novel-context retention experiment has yet been run. Small fast changes are distinct from the founder's 29,264 authored differences and from the two boost edits.

The current-main experimental graph identity test (3/3), CPU cross-graph checkpoint rejection test (1/1) and example static builder test (1/1) passed separately, before this observational patch. The example probe with this patch compiled, ran and performed its own per-trial cold checks; no full-workspace CI or GPU result is claimed. `somatic-summary.json` contains aggregate counts and hashes of retained local receipts, no neural arrays or user data.
