# Detached source assay, not a living-creature result

This whitelist contains only authored Rust source, scientific scalar results, explanatory notes and hash/provenance manifests. It excludes executables, compiled dependencies, compiler logs, original weight assets, checkpoints and raw life data. Linkage entries name historical local paths and hashes; dependency bytes are not included.

## What was measured

One synthetic fixed receptor context, three fresh source arms, hunger/fear/pain {0,.9}³, 48 source iterations each: 1,152 completed iterations. Candidate chemical cues {-0.85,0,+0.85} are decoder-only inputs. Native recurrence, cadence, soma and bounded dendrites run unchanged. There are no world steps, learned-state reads or learning updates. This does not qualify sensory recognition, hazard semantics, action choice, physiological care or future behavior.

The six-row matched-reference repair removes an irrelevant dynamical operating-point offset. It preserves high-minus-low fear/pain sensitivity within 1.252e-6 in measured motor contrast, but DOES change absolute high-drive logits: at iteration48 and fear=pain=.9, positive-cue Avoid changes from -8.492701 to -1.816921. Preservation of sensitivity does not mean preservation of absolute output. Negative chemical produces the opposite sign; chemical[0] is not inherently a toxicity label.

Ingest and Contact offsets also change because this is the previously authored six-row repair, not an Avoid-only production patch. Its output-cut sham isolates the Avoid reference output while retaining the other five edits. The new sham is compiled into its own fresh matching phenotype; validation is not weakened and learned offsets are not used. All source constructors remain opt-in. Nothing here changes existing lives or installs the candidate into current behavior.

## Failed V1 is retained, not erased

The first harness compiled, but its sole native attempt failed at trainer construction with Contract(PhenotypeCompile). It paired the sham asset with the repaired phenotype instead of compiling a matching phenotype. It emitted results only at the end, so the log does not identify the failing arm. Exact prior exposure is uncertain: control flow permits 0, 384 or 768 completed source iterations. Do not claim V1 performed no work or that 768 is established.

V2 is a separately admitted fixed corrective attempt, not a relabeling or continuation of V1. It durably announces each arm and records attempted/completed context counts. V2 completes all 1,152 iterations. Original V1 logs and bytes remain in the private working directory and are intentionally not included in this source-only publication whitelist.
