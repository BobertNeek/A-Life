# Contact20: need-bearing feedback and repeated Pet timing

A fresh seed **2026112000**, with **unchanged Contact20 body and chemistry**, reached
measurable hunger and loneliness through a prospectively fixed **600 native host
steps**. Pet then reduced real loneliness from **0.150000 to 0**. A small repeated
Pet experiment also delivered three real need-relieving experiences per treated
arm. Retained fast-weight contributions were measurable afterward, but neither
experiment changed sampled choices or improved the tested physical behavior.

This extends the newborn zero-need result in [#352](../contact20-feedback-retention-2026-11-14/README.md).
It does not establish learned cue meaning, A-specific credit or a better brain.
The repeated experiment is a controlled fork of the same saved need-bearing life,
not an independent fresh replication. One fresh seed and one simple resource
probe give limited behavioral sensitivity.

## Fixed native lead-in and qualification

The duration was chosen before running: **600 `CpuCanonicalHost::step` calls** in
an empty scene. No threshold changed the endpoint. No food, player cue, clock
advance outside the host, forced action, teleport, neural reset, homeostasis
injection, new chemistry floor or genotype edit was used. All 600 collected rows,
including **101 representative outcomes with `success=false`**, remain local.
Their learning was retained. Family labels are not physical movement: actual
body path length over the empty-scene lead-in was **0**.

At tick 600, actual energy was **0.703399**, hunger **0.469652**, loneliness
**0.150000**, maturity **0.328947**, biochemical expression **1.0**, health **1.0**.
There were **600 decisions**, no sleep and no consolidation. The declared
measurable-loneliness criterion was `>0.0001`; it qualified without stopping
when that threshold was first crossed. This is a partially mature creature,
not an adult-life generalization result.

The native harness asserts exact serialized equality between the carried
canonical newborn biology and `BiochemistryState::new_with_age` for the full
Contact20 genome. The earlier constructor proof remains intact. Its non-brain
chromosomes match the canonical constructor; only the brain's motor head count
changes from one to two. Terminal context stays **Off**.

A twin without the extra checkpoint/diagnostic observer took the same native
lead-in steps. Full checkpoint bytes matched every 60 steps. The tick-600 source
boundary used by both experiments has SHA256:
`7dbdc0abee87291d840bb463bbc9bd5b664ec092b87ff2c6035f82bdeff486f2`.

## Five-arm single-pulse result

A fresh food object was introduced relative to the actual body after the fixed
lead-in. The real A decision was **Approach at tick 600**. The full actual state
after A was branched into None/Praise/Scold/Pet/Slap. Each non-None arm queued
one ordinary native interaction at **601**. B selected at **601** and its
biology/outcome delivered the experience at **602**. The queue was empty for
all later probes. It carried no identity of A.

| Arm | B scalar reward | Actual immediate consequence |
| --- | ---: | --- |
| None | −0.00488842 | No external dose |
| Praise | +0.05591918 | Dopamine 0.500000 → 0.680000 |
| Scold | −0.00998495 | Fear 0.100000 → 0.220000; cortisol 0.200000 → 0.350000 |
| Pet | +0.00234774 | Loneliness 0.150000 → 0; oxytocin 0.500000 → 0.612500 |
| Slap | −0.00994291 | Pain 0 → 0.016000 plus tissue injury |

The four signals were not collapsed into one reward label. Native inherited
biology projected these consequences. Pet's scalar reward exceeded None by
**0.00723616** in this need-bearing condition. In the earlier newborn condition
there was no loneliness to relieve. Age, prior native experience and physiology
also differ between those experiments, so effect-size differences are not a
controlled estimate of loneliness alone.

All five arms ate at outcome tick **616**. Representative and motor candidate
indices matched None throughout the 16 later intervals per arm. There was no
sleep/cadence divergence. At the last decision, **tick 616**, holding the actual
arm's state fixed and removing only its fast-offset difference from same-tick
None gave:

| Arm | Fast component L2 | Max activity change | Max logit change | Changed sampled choice |
| --- | ---: | ---: | ---: | ---: |
| None | 0 | 0 | 0 | 0/16 |
| Praise | 0.00813892 | 0.000149369 | 0.0186103 | 0/16 |
| Scold | 0.00112990 | 0.00000640750 | 0.00219277 | 0/16 |
| Pet | 0.000602610 | 0.00000125170 | 0.00156659 | 0/16 |

Final energy was approximately **0.829189**, except Slap **0.829008**. Slap's
health was **0.994773**; the other arms retained health **1.0**. These physical
costs were preserved and are not evidence of learned useful behavior.

## Repeated actual consequence and timing control

Because Pet had real need relief, the next pilot restored the **actual saved
pre-target tick-600 boundary**, including its acquired fast weights, eligibility,
private activity, memories, topology and sampling counter. The native founder
and Adam checkpoint were loaded exactly. This is experimental branching for a
control, not autonomous forgetting or a reset individual.

The schedule was fixed before execution:

- **Exposure:** ticks `[600,690)`. Three fresh food objects were presented at
  600, 624 and 648, each at world-axis offset `(1.5, 0, 0.5)` from the actual body.
  Existing objects and the body were never moved. Unconsumed presentations would
  remain in the scene and count as failed exposures.
- **None:** ordinary meals with no player input.
- **PetContingent:** one native Pet queued after each actual presented food's
  `consumed=false → true` transition within its 24-step presentation window.
  The sealed physical outcomes and joint channel receipts are retained. No A
  identity or label was inserted into the native queue.
- **PetDelayedYoked:** exactly the contingent arm's external Pet dose count,
  at its actual queue ticks **plus six simulation ticks**, regardless of this
  arm's own meals. This is a delayed, dose-matched external schedule from the
  contingent arm, not internal reward replay or a pure contingency-only control.
- **Quiet:** `[690,714)`, no player feedback and no new target.
- **Fresh probe:** `[714,738)`, a new food identity at world-axis offset `(2.5, 0, 0.5)`
  from the actual body, with **no feedback**. The full native state and
  current physiology were retained throughout.

All three exposure foods were consumed at **605, 629 and 653** in every arm.
The contingent queue times were **605, 629, 653**, delivering at **606, 630, 654**.
The delayed queue times were **611, 635, 659**, delivering at **612, 636, 660**.
Both treated arms had exactly **three** delivered doses. Loneliness fell from
**0.150000 to 0** on the first delivery and **0.0913417 to 0** on each subsequent
delivery. Thus both need/exposure and dose/timing controls qualified in this run;
there were no missing meals or missing doses to discard.

Quiet time did not erase physiology. At probe start, loneliness was **0.150000**
(None), **0.137047** (contingent), **0.133452** (delayed); oxytocin was **0.500000**,
**0.503510**, **0.505088**, respectively. Hunger was **0.310149** in all arms.
Natural probe behavior can still include these current body effects. The
same-state intervention holds each actual arm's current effects fixed.

Every arm consumed the fresh probe target at **729**. All representative/motor
indices matched None across all **138 steps**. Movement totaled **2.915112**
and recorded neural work totaled **7,917,568 synapse operations** per arm.
All arms finished with energy **0.926839** and health **1.0**, with no sleep or
consolidation. Each arm retained **42** representative `success=false` outcomes:
19 during exposure, 8 during quiet and 15 in the probe. These are reported as
representative outcomes; a joint bundle can have distinct channel results.

At the last no-feedback probe decision, **tick 737**:

| Arm | Fast component L2 | Max activity change | Max logit change | Δ log P(actual action) | Changed probe choices |
| --- | ---: | ---: | ---: | ---: | ---: |
| None | 0 | 0 | 0 | 0 | 0/24 |
| PetContingent | 0.00114614 | 0.0000514984 | 0.000911102 | −0.000274978 | 0/24 |
| PetDelayedYoked | 0.000709597 | 0.0000456572 | 0.000990838 | −0.000801671 | 0/24 |

Δ log P is actual minus ablated for the same **fixed actual joint action**, using
native float32 logits and float64 probability evaluation with the native masks
and forced-channel arbitration. It is not food-specific value or the probability
of a newly drawn action. The retained effects differ with timing; this pilot
shows no useful behavioral advantage from pairing Pet immediately after meals.
Other three signals were kept distinct in the five-arm single-pulse experiment;
the repeated experiment intentionally focuses on Pet's measured need relief.

## Interpretation, verification and provenance

Both tools use only public collected/replay interfaces. On a diagnostic copy:

```
offset_copy[i] = actual_offset[i]
               - alpha[i] * (actual_PRE.fast[i] - None_same_tick_PRE.fast[i])
```

All other evidence remains the actual arm's: lifetime, initial activity, EMA,
metabolism, dendrites, encoded input, candidate/memory tape, receptor gates,
structural edges, genetic weights and random counter. Independent Python
reconstructs this subtraction exactly in float32 from the saved native CPs and
checks every other replay field unchanged. The fast component includes
feedback-mediated subsequent biology, experience and learning; it is not the
pure direct synaptic effect of a pulse. Neither the intervention nor a raw
reward is ever sent to a creature.

Full checkpoint observer equality passed at every one of the **80 single-pulse**
and **414 repeated-experiment** boundaries. Diagnostics left actual host bytes
unchanged. Native replay reproduced recorded activations and complete joint
sampling receipts exactly for all **80 + 72** diagnostic rows. None ablations
were zero. All eight arm endpoints and both common branch boundaries typed-cold
restored exactly. Founder/Adam bytes were unchanged in both experiments.

Torch **2.15.0+cpu**, one CPU thread, checked native and ablated forward evaluations
at single-pulse intervals **1,7,15** (15 comparisons) and repeated intervals
**114,121,129,137** (12 comparisons). Maximum logit/activity error was
**5.96046e−8** in each experiment, below the declared **2e−5** tolerance. Small
native effects are established by native f32 comparisons, rather than tolerance
alone. The existing checker now accepts explicit arm names; its default remains
the original five arms. The optional two-arm selection was also exercised.

## Reproduce without overwriting retained evidence

```sh
ALIFE_ASSAY_GIT_COMMIT=$(git rev-parse HEAD) cargo build --locked \
  -p alife_training --features cpu-backend \
  --example feedback_need_retention --example feedback_pet_contingency
asset=docs/experiments/astra-generalization-2026-11-13/pursuit-twohead-contact20.alife-foundation
target/debug/examples/feedback_need_retention "$asset" "$asset.genome.json" \
  /workspace/feedback-need-LOCAL UNIQUE-NEED-RUN 2026112000 16
target/debug/examples/feedback_pet_contingency \
  /workspace/feedback-need-LOCAL/UNIQUE-NEED-RUN \
  /workspace/feedback-need-LOCAL UNIQUE-CONTINGENCY-RUN
python scripts/check_feedback_retention_torch.py \
  /workspace/feedback-need-LOCAL/UNIQUE-CONTINGENCY-RUN \
  --arms None,PetContingent,PetDelayedYoked --intervals 114,121,129,137
```

Adjust binary paths for `CARGO_TARGET_DIR`; this Cloud task used its existing
`cloud-cpu-validation/env.sh`. The existing raw run directories are
`/workspace/feedback-need-LOCAL/fixed600-2026112000` and
`/workspace/feedback-need-LOCAL/pet-contingency-2026112000`. Create-only storage
rejects reuse. Raw CPs, sensory/neural/gradient arrays, eligibility, Adam, complete
