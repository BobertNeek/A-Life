This source-only research result wires an observed feature basis into an explicit new N2048 ABI. It does not establish that all biological drives work, that the coefficients are appropriate for a creature, or that any creature learned avoidance. No default brain or existing creature is changed.

## Mechanism and accounting

The opt-in selector uses class 5, canonical tag 10, 2,048 neurons and 34,048 static synapses. It adds 1,280 candidate rows without dropping raw features or recurrent connections. Within the fixed 54-lane candidate row, lanes 36..45 replace ten previously unscored cognitive lanes. Raw 0..23, memory 24..35, remaining cognitive 46..52 and grip 53 retain their roles. This does not preserve every former cognitive port.

Derived inputs are observed object presence, positive/negative taste, hot/cold surface excess, perceived peer match, intrinsic vocal opportunity and observed current thermal contact. Personal novelty and predicted play remain reserved zero. Thermal features are signed observed surface extremes; unsigned body-temperature stress is not signed core temperature. No warming/cooling competence follows.

Research cost policy is **768 Q24 per candidate = old 128 + 160 added products × existing synapse rate 4**. Candidate counters retain candidate semantics. This is an authored incremental cost policy, not a sixfold runtime measurement or a recalibration of the old lump rate. The extra rows are not compute-matched to old class 3. Old policy serialization, canonical bytes, digests and costs remain unchanged in the covered checks.

Fresh genetic transfer maps all **32,768 full persistent addresses**, including duplicate ordinal, rather than packed indices. It preserves exact source genes, including a deliberately negative shifted readout, seed, dynamics, cadence, alpha and receptor parameters, and checks exactly **1,280 newly zero rows**. A fresh unbound source is rejected. This helper accepts no acquired organism/private/optimizer checkpoint and is not retained-state migration.

## Preserved failures and limits

The initial CPU fixtures failed before neural work because observed topology evidence was missing (`d7f68ceb`), then trainer construction rejected an unbound fixture asset (`17cb6f22`). Correct fixture setup used the normal observed-sidecar and explicit asset admission paths. Guards were not weakened. The software test first failed compilation for a missing public snapshot-type import; its original failure is retained. No software numerical failure occurred in the recorded successful run.

No outcome learning, learned avoidance, actual GPU backpropagation, nonzero accumulated eligibility, nonzero memory/grip preservation, physical GPU behavior, world/CPU-host admission, whole-organism continuation, performance calibration or general biological drive competence is qualified. Future host/genetic integration is outside this publication. Legacy baselines and acquired-state data are not rewritten, reset, migrated or uploaded.

The additive publication tree itself was **not executed**. Source identity, the inherited bounded test-only difference, log provenance, original hashes and reproduction instructions are documented in [PUBLICATION.md](PUBLICATION.md).
