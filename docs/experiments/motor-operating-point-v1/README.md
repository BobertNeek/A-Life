# Motor operating-point candidate V1

This independent weight-only candidate follows the measured detached multi-drive routing assay. It does not modify or re-label frozen whole-care6, the default ABI, existing assets or learned creature state. It preserves all 64 inherited dendritic branches. Each candidate receives a separately computed immutable foundation-asset digest; the default graph must reject its explicit research-graph coordinates.

The first factorial experiment separates two effects:

1. **Differential readout:** replace the frozen +5 reference contribution in Approach/Inspect with a -1 contrast. Rest's existing contrast stays unchanged. No recurrent edge is changed in this arm.
2. **Tonic counterbalance:** use previously unoccupied Temporal relay neurons. A positive inherited interoceptive tonic input feeds Reserve, a signed negative Modulatory edge creates negative relay state, and a nonnegative MotorProposal edge counterbalances the saturated signal/reference motors. Existing need relays cannot be reused. The experiment sweeps output gains 4, 6 and 8 rather than assuming weight sign determines a correct operating point.

Original, readout-only, three tonic-only, and three combined arms use matched conditions and preserve optimizer state. The supported scope is hunger/fatigue/ATP and their conflicts with the same frozen sensor/receptor context as the routing assay. ATP is measured as a negative availability perturbation but is not yet rewired by this operating-point candidate; zero ATP sensitivity remains a known limitation. Recurrent competition will be a separately tested factor, not hidden inside this correction.

The candidate is not a complete biological policy: social, thermal and reproductive opportunity grounding remain unresolved. Contact remains generic object grabbing, not a social remedy. No autonomous world run, learning or promotion is authorized by an assay result. The measured outcome and qualification are recorded in RESULTS.md and receipt.json.

## Strengthened controls before the first run

The complete V1 all-drive set is retained, including curiosity (Inspect is changed), pain/fear, temperature, boredom, unbound Extension1 and original paired conflicts. Hunger/ATP, fatigue/ATP and triple conflicts are added. The recurrent operator receives 24 simultaneous decoder probes, three feature contexts times eight families; candidate features have no recurrent feedback in this detached operator. Exact frozen-arm comparison against all 270 published baseline snapshots is required by `summarize.py`.

Every changed condition's cut-input sequence must exactly equal its baseline sequence. The complete 64-frame activation trace must be identical for each matched pair differing only in differential decoder weights. Signal/reference traces retain their signs; positive and negative saturation counts are both reported. Counterbalance may share a constant relay across motors, but may not overwrite any pre-existing nonzero middle/output edge or any occupied need relay.

Baseline drift from frames 32→64 and 48→64 is recorded rather than assuming a 32-frame warm-up proves convergence. Exact final-step bias, encoded input, recurrent sum, dendritic sum and homeostatic subtraction are audited using a native replay of the identical prefix with the last frame stopped after three microsteps. The reconstructed fourth-step motor activation must match the ordinary native result within 1e-6. This separates an observed saturated operating point from any inference about its cause. This diagnostic preserves all dendrites; it is not a dendrite-removal ablation.
