# Results: the existing drive wiring is not adequate

**Detached native CPU evidence only.** The corrected assay completed 144 replay evaluations, 9,216 fixed-context frames, 135 exact input-cut sequence controls and two example tests. It executed no world or learning steps and read no existing creature/checkpoint. GroundedObjectSlotsV1, seed 7, 2,048 neurons, 32,768 synapses, four microsteps per frame and 64 inherited dendritic branches were used in all three arms. This is not a Terrain/heard-language or integrated behavioral qualification.

`results.json.gz` contains full signed family vectors, individual motor activation traces, expressed biochemical receptors/emitters and separate structural/effective connectivity. `summary.json` is regenerated by `summarize.py`; `receipt.json` binds source, executable and result hashes. Optimizer/weight preservation assertions passed in every arm.

## Main findings

1. **Default compiled graph: every one of the 11 drive inputs is disconnected from every decoder motor population.** Structural recurrent reachability is zero at motors. Including nonzero inherited dendritic edges does not restore these paths. Every measured motor and neural-logit perturbation is exactly zero through all 32 post-perturbation frames, across all three candidate-feature contexts and paired conflicts. This is a graph-level failure, not merely an unfavorable coefficient. Innate decoder urgency remains active and is explicitly separate.

2. **Graph repair restores reachability, not sensible selectivity.** In the repaired graph with genetic weights, every input reaches all 16 decoder motors per family. In the nutritious-contact fixture, raising fatigue changes Ingest by +0.022933 but Rest by only +0.000000954. Hunger changes Ingest by +0.033099. These are small, broadly mixed responses, not evidence of biological drive arbitration. First observed responses above 1e-6 appear at sampled perturbation frame 2, demonstrating why one-frame checks can miss paths.

3. **Whole-care6 silences several meaningful drives at the neural path.** Loneliness, ATP availability, temperature stress, reproductive drive and canonically bound boredom have zero nonzero-weight motor reachability and exactly zero measured motor/logit change. Artificial Extension1 input is also disconnected, but canonical biology does not bind that channel, so this is not an unmet biological deficit. Curiosity/reproduction are not automatically welfare deficits.

4. **Whole-care6 Rest is almost saturated before fatigue changes.** At the settled baseline, all Rest motors are about 0.999913–0.999949; high fatigue moves its signal motor to about 0.999981. The resulting neural Rest change is only +0.000065446. In contrast, the hunger-sensitive Ingest motor begins at 0.243061 and rises to 0.517072, producing +3.123727 in the same contact fixture. Positive fatigue weights and a directed path therefore do not establish an effective Rest drive.

5. **A strong tonic reference favors Approach before any hunger increase.** Whole-care6's balanced nutritious-contact neural logits are approximately `[0, 0.000072, 2.699792, 10.798813, 3.815085, 0.439799, 0.718163, 0]` in family order Idle, Rest, Inspect, Approach, Avoid, Contact, Ingest, Other. Its Approach/Inspect readouts add a +5 reference contribution, whereas Rest subtracts its reference. Raising fatigue adds a separate innate Rest bias of +1.344, but that is far below the fixture's tonic Approach score. This is a readout/operating-point mismatch, not justification for forcing activity.

6. **The selected chemical cue changes signed readout effects.** Whole-care6 fear/pain raises Avoid for the aversive-contact fixture and lowers it for nutritious contact; distant zero chemical cue yields no corresponding neural Avoid readout. The native innate avoidance fallback is separately reported. This is why an activation increase, a weight sign or a path alone cannot be called useful avoidance. Temperature still lacks the whole-care6 neural route, even though innate urgency has a temperature mask.

7. **Conflict tests expose additive proposals, not a demonstrated reconciler.** Hunger+fatigue retains roughly +3.124 Ingest neural change but only +0.000065 Rest; hunger+pain combines food and aversion proposals. Fatigue+boredom is indistinguishable from fatigue at the neural readout because boredom is disconnected. No winner selection, autonomous behavior or learning was performed.

## Boundaries and next experiment

The zero neural results do **not** mean these drives have no organism-wide effect: biochemical motor confidence, recovery triggers, receptor gains and cadence are held fixed here. ATP is tested by decreasing availability from 0.75 to 0.1, not by treating high ATP as distress. Innate and biochemical effects must not be confused with recurrent efficacy.

Contact is a generic object-grab family in the present repertoire, so routing loneliness directly to Contact would not repair social motivation. Thermal and reproductive opportunities likewise need truthful grounding rather than arbitrary commands. Missing semantics remain explicit.

A separate weight-only operating-point candidate is warranted: retain inherited dendrites, use signed upstream Modulatory tonic state with nonnegative MotorProposal edges, and test differential reference readouts as a separate factor. Only then assess an independently factored hunger/fatigue/ATP recurrent competition circuit. Frozen whole-care6, existing assets, inherited branch coordinates and old receipts remain unchanged. No candidate is promoted by this report.

## Fixture correction

A preliminary unoptimized run used simplified intrinsic Idle/Rest features. The final published run uses the production intrinsic-action-basis helper, including Rest's posture lane. The correction changes intrinsic readout operating values in genetic arms; all individual motor activation traces matched the preliminary run exactly. Only final corrected data are published. Source and executable hashes distinguish the two runs. Input-cut equality in the final run is established on the complete replay sequence and reuses its deterministic baseline evaluation; the preliminary run also evaluated each cut separately with exact logit equality.
