## What this establishes, and what it does not

The null precedes retrieval. It does not establish that the neural comparison
is too weak, that Rest is undesirable, or that a learned policy succeeded.
The journal did not record every binding predicate, so its precise first failed
predicate cannot be reconstructed from this life.

Source inspection found a real general error: physical receipts retain commands
after the world's embodiment/proprioception/capacity adaptation, while the
admission code compared them directly with requested commands. V3 must reuse
that exact trusted adapter, preserve action/target/physical identity checks and
record specific failure reasons. This is a new source revision and new fixture,
not a retrospective repair of V2 evidence.
