# Observed need-consequence evidence, opt-in research component

This adds a separately instantiated evidence store for raw measured changes in
all eleven biological drive lanes. It does not modify MemoryBank V2, existing
reader semantics, acquired state, genes, optimizer history, replay or save formats.
No gameplay/default, CPU/GPU policy reader or persistent host attachment is added.
The separate approximate retrieval experiment is not part of this component.

Only a validated sealed observation with measured physiology and an observed
representative target can be admitted. Each joint interval contributes one
association, never a full causal reward to every motor channel. Unknown remains
distinct from measured zero, and opposite signed outcomes are not pooled away.
Sources are validated, byte-bounded and replay-protected through pruning/restore.

## Native results and the important failure

Exact ordinary-main source 493bb172 passed 98 tests: 11 new core, 1 fixed world
fixture and 86 legacy memory/query/experience/physiology/digest guards. One existing
manual benchmark was ignored. Strict core/world lib/tests Clippy, workspace
formatting, static core boundary and diff checks pass. The world check is focused,
not a full world-suite or hardware claim. QUALIFICATION.json binds exact source
and finite log hashes. Publication only moves documentation and adds metadata;
all five source/test files are byte-identical to the qualified source.

Real peer contact decreased loneliness by 0.007499993 in one 20 Hz interval;
equally positioned toy and separated-peer controls measured zero. Passive clones
showed the same change, so this is interval association rather than Inspect
causality. Fixtures initialize juvenile age 600, not 600 lived ticks or adulthood.

The Inspect command is prescribed. Its storage contract test constructs a synthetic
CPU-neural decision envelope with a chosen score/confidence and zero reported
neural work; no network selected it. The body changes and physical receipts are
real, but admission under that test envelope is not proof of authentic neural
selection or a working neural-to-memory pipeline. Real selection remains a
separate qualification requirement.

Exact source-context recall and byte-exact restore pass. However, all three actual
next-world queries return Unknown despite the same target and family. This is
honest evidence-storage qualification, not useful learned recall or a repaired
policy. The frozen results retain that limitation; no creature was reset to make
the query match.

## Cost and next work

Bounds are 32 records, 128 KiB per sealed source, 1 MiB per store, 32 query scans
and 8 returned records. Actual fixed-world sources cost about 16 KiB each. Keeping
full validated sources is an evidence prototype, not scalable population memory.
Before runtime attachment, bind world/life/genome/checkpoint ownership beyond
OrganismId and qualify compact evidence, context tolerance, current-pressure
conditioning, confidence, real selection and CPU/GPU parity separately. Targetless
Rest/Idle is currently Unknown; this does not deny their biological effects.

The fixed plan, interface and detailed results are preserved alongside this file.
The design remains inspired by [Sparks of Weight-Space Programming](https://rikiyat.github.io/blog/weight-space-programming/),
including targeted repair, whole-network construction and iterative feedback.
A storage or fixture pass is not a claim of synaptic learning.
