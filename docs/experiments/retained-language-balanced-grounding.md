# Independent-seed balanced grounded-language continuation

This CPU-only disposable-founder experiment extends draft #254. It retains the
exact measured V14 grounded actor, native Adam moments and integer optimizer ages
at step 320. Untouched, grounded, shuffled and no-new-request arms begin from that
same actor. The three continuations take 48 native updates (two rounds of 24).
Default brains, the experimental V3 identity, source private recovery and all
previous negative evidence remain unchanged. No creature is promoted.

## Teaching and assessment

Four training layouts per round each fork the same actual world/private parent for
`eat food`, `get food` and `get toy`. Teacher and player cues both occur every two
ticks in a fixed eight-tick window; each life runs 24 native decisions. Grounded
teacher cues match the offline requested lesson, shuffled cues use rotating
nonidentity permutations, and no-new-request receives no teacher cue. All arms
retain earlier language history, real self-speech and truthful narration targets.
This is a continuation ablation, not a language-naive control.

Concrete native imitation classes have equal total mass (0.4 / 3 each). Additional
native conditional cross-entropies balance EatFood/GetFood verb choices and
GetFood/GetToy noun choices (0.075 per class). Fulfilled, factual narration and
other rows each get 0.1 mass. Conditional masks select real legal candidates;
they do not add actions or provide evaluation targets. Speech targets require a
real acquisition or consumption, begin after the instruction window and last at
most three eligible quiet rows. Impossible EatToy events are never fabricated,
so truthful speech lexical marginals cannot be exactly factorially balanced.

Only the existing 4,096 native action/speech decoder coordinates train. Frozen
weights, moments and ages are checked exactly after each update. Native recurrent
inputs, private state, routes, biological receptor modulation and sealed outcomes
remain in each actual replay row. There is no independent text classifier.

Six held-out environment/sampling seeds are 2404507, 2509943, 2608889, 2700419,
2805623 and 2907709. Training uses eight different seeds. Object allocator IDs,
spawn order and positions change; actual food, movable toys and visible distractors
remain in the authoritative world. Each seed has paired EatFood/GetFood/GetToy and
silence trials. Evaluation has no teacher or semantic prior, no forced action and
no evaluation update. Native ownership, actual consumption with nourishment and
executed Vocal payloads determine outcomes, rather than desired labels or logits.

Pre-sleep and post-sleep results are separate, with N=6 seed units in each phase.
The same seed before and after sleep is dependent, not two independent samples.
Sleep uses the existing induced RecoveryProtocol and must consolidate and wake;
there is no matched awake-delay control or spontaneous-sleep causal claim. These
are six environments for one trained founder, not six independent trained brains.
All four arms receive full fresh-process trace/state/next-Adam checks.

## Preserved V15 fixture diagnostic

V15 source `f406f9feb63c7b1dd912da39c68955a89a3429b0`, binary SHA-256
`a3aab635685c27f54e02b91b5fc428d2b3ca58f910a3d3445693f8e2b3b0e07d`,
ran for 1420.740 native seconds (1420.781 external seconds). Every arm completed

fresh process. Each continuation collected 576 genuine training decisions.

A physical positive control exposed an invalid feeding geometry: the near toy
occludes food after pickup at the normal forward carry grip. Eat then disappears
from legal visible candidates while the food remains owned. The experiment keeps
the engine visibility rule intact and versions the corrected fixture separately.
All V15 raw traces, exact recoveries, measured executable and negative results
remain in `/workspace/language-balanced-v15-run`. V15 is diagnostic evidence,
not an interpretable retained verb-learning test.

## Corrected V16 fixture

V16 moves toys clear of the food carry/mouth line in all four training and six
assessment layouts. Direct registered-command positive controls establish actual
pickup followed by consumption and positive energy gain before learning is
scored. These scripted controls are separate from unforced evaluation.

V16 assessment traces retain the first complete native row for each life,
complete action/world patches on every row and a SHA-256 of every full native
row. Full actor/host/private recovery remains saved. Cold recovery regenerates
and checks full-row digests and next-Adam/private-state identity. V15's original
full-row format and replay path are preserved. Training rows remain complete.

## Provider boundary

The teacher is scripted ordinary nursery speech. Luna's earlier Responses
WebSocket 401 remains a stop: no retry, credential change, alternate endpoint or
transport fallback. No delivered learned SLM output is claimed.

## Reproduce

```sh
experiment_retained_language --disposable-public-founder --experimental-word-bridge \
  --balanced-visible-readout /absolute/path/to/measured-V14-run \
  --output NEW_DIRECTORY --seed 847501 --rounds 2 --epochs 24 --decisions 24
python scripts/summarize_balanced_grounding.py NEW_DIRECTORY
```

The older `--balanced-readout` flag retains the V15 geometry and trace protocol
for reproducibility. Both require this pilot's measured public V14 source and
write a new directory. Neither path accepts or changes live training.
