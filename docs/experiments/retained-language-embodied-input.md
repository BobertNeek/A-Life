# Experimental embodied speech inputs

This separate opt-in native CPU experiment follows the negative [word and
curriculum pilots](retained-language-curriculum.md). It changes no default brain
and does not migrate an accepted creature or an existing private life.

## Evidence and change

The measured V1 sparse phenotype has no encoded path from holding an object,
positive ingestion taste, hunger, any homeostatic lane, or proprioception to the
speech source bank. These claims concern encoded paths: global biochemical
receptor modulation still influences the native dynamics. Some visual, acoustic,
ground-contact and aversive-taste lanes already reach speech. The preceding
objective fixes generated truthful activity labels and updated speech weights,
but all measured V1 evaluations remained silent through optimizer step 192.

`TwoTokenAndEmbodiedSpeechV2` keeps the V1 raw two-token projection and adds
30 assignments to existing speech source neurons: all eight raw tactile channels
and all 22 raw homeostatic channels, each at gain 0.5. These ordinary bodily
signals include contact, holding, actual ingestion taste and native need state.
The encoder receives no completed-event label, target token, requested action or
manufactured reward. Existing sparse synapses and native recurrent/decoder math
remain unchanged. This is a direct sensory shortcut experiment, not evidence of
language comprehension.

A restricted native actor fork accepts only an exported experimental V1 founder,
rejects ordinary or live-policy compiler inputs, and verifies the source topology
and foundation. It retains every weight, both Adam moments, integer ages, global
step and stage mask. V2 has a distinct phenotype/compiler identity. The original
actor is unchanged, and its private checkpoint cannot restore under V2. Fresh V2
cohorts create their own lives. Historical default and V1 identity bytes remain
unchanged; profile information must accompany a foundation asset.

## Matched protocol

Both actual step-192 histories fork to V2. Before offline updates, each receives
an untreated V2 assessment with nine scored lives. One round then collects eight
paired real 32-decision lives from four common snapshots with opposite requests.
Grounded and shuffled request alignment follow the prior counterbalanced
curriculum. Both arms receive truthful labels for completed physical activity.
Narration follows only sealed actual ingestion or verified toy ownership change,
including nonrequested activity; ordinary speech enters through spatial hearing.

The native recurrent, action and speech coordinates train for 32 updates while
all other coordinates and their optimizer histories remain frozen. Action loss
uses audible requests or eligible narration. Speech uses the previously tested
0.9 positive / 0.1 silence corpus budgets to equalize shared presence-gate weight;
no decoder threshold changes. Training targets stay offline.

Final assessment uses ordinary player food/toy requests plus a silent control,
no teacher actor and no semantic prior. Each cue trio starts from the same
private snapshot, with food, toy and a visible distractor. Contact/near positions
are relocated relative to training. No evaluation action is forced. A third trio
follows one shared native RecoveryProtocol sleep/consolidation ancestor. This
is induced native sleep, not spontaneous natural sleep. Full assessment is
repeated in a fresh process with exact trace, private continuation and next-Adam
checks. The untreated baseline is evaluated in process.

Request compliance is the first genuine physical completion matching the actual
request; a missing completion is a failure. Silent trials have no compliance
score. Narration requires the exact two expected activity words in an actual
emitted world utterance at an eligible time. Physical event counts and utterance
counts are separate. Token logits, heard frames and optimizer updates alone do
not establish retained language.

The grounded final first activity is food in every cue fork, including toy and
silent requests. The shuffled result also remains cue-insensitive in several
forks. Acquisitions include release/reacquisition; they are event counts, not
independent task successes. Each training arm generated 10 actual completed
activities and 30 positive narration rows: grounded eight toy/two food events,
shuffled six toy/four food. These are genuine physical consequences, yet neither
arm acquires the target language behavior. Lower offline action/speech losses
are not evidence of retained comprehension. **The experiment remains negative.**

Captured-state gate reconstruction explains the immediate silence: grounded
selects Vocalize 153 times (25 eligible rows), shuffled 166 times (42 eligible
rows), but every eligible first presence gate remains negative. Final eligible
raw presence ranges are approximately −0.258 to −0.170 and −0.265 to −0.170.
This is a post hoc float32 reconstruction of the unchanged native speech matrix
using actual final activations, weights and effective offsets, not a behavioral
or learning score. Actual world utterance counts above are the primary outcome.

Both final arms pass full fresh-process trace comparison, exact private
continuation, next native Adam update and recovery-sleep assessment. The ordinary
historical recovery and the preceding V1 complete assessment also reproduce
exactly under the V2 code. All source actors and private recoveries are preserved.
The 86 core compatibility tests, 39 native backend/collector tests and nine normal
pilot tests pass. Strict Clippy and the headless check pass. The separately
invoked real-provider probe from the preceding stage remains a failure, not a
passing integration test.

[Full source-safe measurement](retained-language-embodied-results.json).
This is one founder seed continuing two distinct treatment histories, not a

No natural-sleep, far-navigation, CFF ChiChi or successful SLM-learning claim is

## Reproduction

```sh
target/debug/experiment_retained_language --disposable-public-founder \
  --experimental-word-bridge \
  --fork-embodied-speech /absolute/measured-v6-step-192 \
  --output /absolute/new-v7 --seed 847501 --epochs 32 --rounds 1 --decisions 32
```

The source must contain its original matching results and exact recovery data.
Only aggregate source-safe measurements belong in Git; raw traces, founders and
private recoveries remain local. This experiment uses a scripted teacher. The
existing real Luna provider probe failed before delivering any model output;
local inference still lacks an authorized compatible model/server installation.
