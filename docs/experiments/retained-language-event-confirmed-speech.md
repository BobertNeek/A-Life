remain intact. Only disposable copies of the measured V16 grounded actor train;

## Evidence and correction

The saved V16 training-row audit finds grounded 83, shuffled 91 and no-new-teacher
90 positive speech labels. None of the 264 labels coincide with any heard token.
All three native heard-word inputs are exactly zero on the selected factual
positive rows. Native speech gradients have 864 nonzero decoder coordinates;
a 0.25 pulse on the noun-input source lane changes the head gradient L2 by
0.098525, 0.103639 and 0.101992 for EatFood, GetFood and GetToy rows. These are
frozen-row signal-path diagnostics, not world transitions or learning outcomes.
Actual quiet-row conditional decodes are all `get food`.

The native speech target uses bit-wise squared error. The uniform three-class
constant optimum has majority verb Get and noun Food, yielding `get food`.
A unit test verifies that centroid; it does not claim that other body/memory
signals are absent or that this is the only cause of collapse. The measured
mismatch is that word input is systematically absent at positive narration labels
while V3's direct word cells have immediate dynamics.

The explicit `--event-confirmed-speech` stage moves positive speech supervision
into the existing eight-tick cue window, after a real physical event matching the
requested lesson. It never labels a cue alone, a food pickup as eating, or an
uncompleted requested activity. Grounded/shuffled/no-new-teacher receive the same
factual eligibility rule and native objective weights. Shuffled nursery words
use the existing rotating permutations; no-new-teacher gets no new word cue.
Completed event labels train the ordinary native Vocalize choice and speech
payload. All physical transitions and rewards remain native. This is prompted
rehearsal, not autonomous narration or general comprehension.

The matched arms clone the same retained V16 grounded actor and Adam history at
step 368. Untouched stays unchanged; three arms receive two rounds of 16 native
updates (32 total), using the existing four training layouts per round. Only the
native action/speech decoder mask trains; all frozen weights, moments and integer
ages remain exact. Cohort-private state is native; this does not transplant the
original source individual's lifetime into another world.

## Assessment and controls

Teacher and semantic prior are absent. Ordinary player requests and silence use
the same fixed eight-tick timing. Six held-out world/sampling seeds and actual
changed object IDs, spawn orders, positions and visible distractors match V16's
fixture. Physical acquisition and consumption, nourishment, executed utterances,
event-confirmed cue-window declarations and premature requested phrases are
reported separately. A spoken command can be mere parroting; only declarations
after a real matching event qualify as confirmed reports. Evaluation actions are
never forced. New opportunity metrics are versioned and cannot be compared to
V16's quiet-after-eight-ticks labels as if they were the same measure.

Each seed is assessed pre/post induced RecoveryProtocol sleep; these are paired,
not twelve independent units or independent trained founders. There is no awake-
delay or spontaneous-sleep control. All four arms receive complete fresh-process
assessment/full-row-digest/private/next-Adam checks. The saved actual gradient is
used in the next-Adam continuity check, not recomputed after recovery.
