# Cooldown-aware report choice and native noun margin

This is one bounded CPU-only continuation of the measured disposable V17 grounded
actor. The untouched control and three trained controls clone the same actual
step-400 actor, native Adam moments, integer ages and configuration. Two rounds
of 16 updates give 32 new updates per trained arm. No accepted brain, original
private life or default compiler identity is migrated or overwritten.

## Focused correction

The preceding native diagnostic found five cooldown-eligible factual states with
a correct conditional payload but no Vocalize choice, two further correct states
on cooldown, and six GetToy states with one wrong noun bit (`[9,3]` vs `[9,2]`).
It did not establish weak raw cue encoding as the main bottleneck.

The explicit `--report-choice` stage changes only offline supervision:

- A report action target requires a genuine matching prior event, the existing
  eight-tick cue window, and the world's actual speech cooldown eligibility.
  Blocked states receive a legal quiet Idle action label. After an actual correct
  Declare is emitted, the life receives no repeated report target.
- Eligible report-choice cross-entropy has total weight 0.4 instead of 0.1.
  Physical concrete, verb/noun contrast, fulfilled and other action terms retain
  their prior weights. These are objective coefficients, not probabilities.
- Factual Food/Toy speech gets a native contrastive margin against the observed
  wrong noun code 3. Both losses use the same real row and existing native speech
  backward path. The added loss is `max(0, 0.02 + L(true) - L(wrong))`, with observed
  Food/Toy classes normalized equally. The wrong code is a negative alternative,
  never a fabricated event or reward. It contrasts a single required zero bit;
  this does not remap runtime tokens, constrain decoding to a vocabulary, or ban
  code 3 globally. Retention of other lexical contexts is not measured.

The world exposes its existing cooldown predicate without adding state or changing
cadence: eight ticks for Player-prompted speech, 32 otherwise. The existing neural
execution guard reuses that same predicate. Teacher speech remains spontaneous
for this guard, as before. The query does not reserve speech or bypass any other
world validation. Conditional payload targets may still train while speech is
blocked; action labels never request a blocked report. No external completion or
cooldown label is injected into the actor's neural inputs.

All events, biological rewards, candidate selection, physics and utterances come
from the canonical native host. Only existing native action/speech decoder
coordinates train; every frozen weight, moment and integer age must remain exact.
Speech supervision follows real consumption or acquisition, not hearing alone.
All previous objective paths and the V17 assessment protocol remain available.

## Matched assessment

The six prior held-out seeds, changed positions/object IDs/spawn orders, visible
distractors, EatFood/GetFood/GetToy counterfactuals and silence are unchanged.
Teacher/prior are absent. Actual actions and speech are unforced. Physical
ownership, ingestion and nourishment, timely factual/requested declarations,
premature phrases, paired speech and joint physical/speech distinctions are
reported separately. Conditional payloads from the reused read-only diagnostic
are separate and never counted as spoken success.

Untouched, grounded, shuffled and no-new-teacher share the source actor, seeds,
layouts, eligibility rule and update count (untouched takes none). Shuffled
nursery words use the prior rotating nonidentity permutations. No-new-teacher
retains earlier language history and natural self-speech; it is not language-naive.
Real positive-label counts may differ with actual physical trajectories; absent
events are never manufactured to balance counts.

Each seed has paired pre/post induced RecoveryProtocol sleep. The same seed does
not double independent N. There is one trained founder, no new blind seed set,
no spontaneous-sleep or awake-delay causal control and no new lexical combination.
Full fresh-process assessments, private state and the next native Adam update
must match. That continuity check uses the saved real gradient, not a newly
recomputed gradient after reload.

## Reproduce

```sh
experiment_retained_language --disposable-public-founder --experimental-word-bridge \
  --report-choice /absolute/path/to/measured-V17-run --output NEW_DIRECTORY \
  --seed 847501 --rounds 2 --epochs 16 --decisions 24
python scripts/summarize_balanced_grounding.py NEW_DIRECTORY
```

This stage admits only the measured public V17 source and writes a new directory.
The teacher is scripted ordinary spatial nursery speech. No learned SLM delivery,
Luna 401 retry, promotion, live/PC training change or source checkpoint mutation.
