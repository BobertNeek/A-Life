This is an experimenter intervention in a simulator branch, not acquired learning,
not an inherited genetic change and not a demonstrated improvement.

native trainer copy. Only finite, unique, in-range coordinates in the existing
ActionCandidate, MemoryContext or CognitiveContext decoder heads may change.

configuration, stage mask, source asset, phenotype and replay execution choice
remain unchanged. Requested float bits, including signed zero, are retained.

policy, validates the restricted transition, stages an original host clone and
proves its full checkpoint differs only in `founder_weight_digest`. A separate
native cold reconstruction validates exact preservation before commit. No world,
biology, genome, recurrent state, fast/lifetime weights, eligibility, memory,
tracking, hysteresis, prediction, history, tick or sampling RNG is reset or edited.
The original branch/trainer remain available. An unchanged canonical digest,
including a signed-zero-only digest collision, cannot establish a new policy.

The existing full policy-weight digest is the changed identity; no new sensory
width, memory route, checkpoint schema or decoder arithmetic is introduced.
The live organism's old blanket genetic-weight equality guard remains exact for
all non-permitted coordinates. It now admits finite changes only in the three
readout heads, while retaining all phenotype, timing, pending-credit and sealed
outcome checks. Both neural forward and normal plasticity use the actual policy
base plus the original acquired offsets. Non-readout/recurrent overrides remain
invalid. Older software can parse the saved format but does not support advancing
these calibrated policies; it rejects them rather than executing different math.
Unchanged genetic-equal policies preserve their prior behavior.

This is not an optimizer update: moments/ages are preserved, not represented as
new training. Later individual credit still comes only from real sealed outcomes.
Policy validation/calibration is external experiment bookkeeping, not fabricated
creature reward or body-state work. Neural/synaptic accounting and ordinary body
