# Sleeping-body withdrawal: runtime integration

This connects the already-merged physical body component to the ordinary GPU
runtime only for organisms the real scheduler places across a non-Awake edge.
Awake organisms lacking a prepared decision are not classified as sleeping.
Completed consolidation holds still have a body interval even when no recovery
dose is scheduled. Voluntary bodies already advanced are not advanced twice.

A fresh physical hazard dose can produce one bounded withdrawal and suppress
physical sleep recovery. Known contact supplies direction; fresh unlocalized
damage reverses the current heading without changing yaw. Quiet intervals and
chronic injury alone do not renew movement. A blocked withdrawal still interrupts
recovery. This does not itself awaken cognition, dispatch an awake neural batch,
create a voluntary episode or apply policy credit.
