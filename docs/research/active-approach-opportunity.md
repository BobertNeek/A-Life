# Explicit active Approach opportunity continuity (CPU research)

This opt-in CPU adapter extends executed Approach attention feedback. It does
not alter the genome, calibrated founder policy, neural competition, sensory
ABI, memory mode, attention salience or the existing 0.05 hysteresis margin.
It is an experimenter-selected capability, not evidence of learned improvement.

`CpuCanonicalHost::fork_with_active_approach_opportunity_for_research` creates an
immutable copy of a CP17/coverage2 host as CP18/coverage3. Attachment changes only
those two identity fields. Initial active intent is absent; acquired attention,
world, physiology, age policy, recurrent/private state, learning history, RNG,
founder weights and Adam state remain unchanged. Old readers reject CP18.

Only an actual successful targeted canonical Approach (primitive101) can renew
intent. The existing executed-action feedback resolves the authentic observed
tracked identity; no second memory query or synthetic action is introduced.
Every other new decision, including Avoid, failed or untargeted movement and
NoMove, clears intent. Intervals without a decision preserve it. Current observed
membership gates opportunity admission. Missing/consumed targets are not invented.
Intent provenance is included in the resident digest when present.

The existing V1 selector runs unchanged. One active observed object may replace
only the last unprotected prefill slot, preserving real contact, the actual first
focal object and the original rotating residual slot. Already selected identities
consume no extra capacity. With no spare slot the original selection is retained.
Uncrowded scenes already admit all objects and need no insertion. All six existing
object action families compete normally; no object kind, desirability or goal ID
is used. Existing focal routing does not become an active-intent policy override.

The overlay receipt records the requested identity, observed slot, original and
final selection, protected slots, admission reason and additional logical work.
An admitted replacement reconstructs only its six candidate records rather than
building another full candidate vector. No-admission paths reuse the V1 receipt.
Logical units explicitly charge bounded field, lookup, materialization and
validation operations; they are not machine-instruction counts or measured
runtime speed. Existing V1 work stays unchanged. Overlay work, intent maintenance
and existing Approach feedback join attention, grip and coverage work before the
single existing native cognitive debit and credit path. Sleep is not forced.

Qualification must distinguish fixed-row selector opportunity changes from actual
neural choices and biological outcomes. Retained-row probes do not establish meals,
learning, reduced harm or a successful trajectory. This capability is CPU-only;
full-game/GPU execution is not qualified by these CPU tests. Old adapters retain
exact native checkpoint, replay and accounting semantics without automatic
migration. No default or selected-brain change is implied.
