# Executed Approach attention feedback (CPU research)

`CpuCanonicalHost::fork_with_approach_attention_feedback_for_research` creates an
explicit opt-in copy of a CP16 opportunity-coverage-v1 host. The copy uses CP17
and coverage version 2. Attachment changes only those two identity fields; it
preserves the original host, current focus, private state, world, existing age
policy, sampling state, genes, calibrated founder and optimizer. No previous
intent is seeded at attachment. Modes 14/15 and GroundedObjectSlotsV1 are required.
Older readers reject the new identity. Existing identities keep their exact path.

After a native successful, targeted locomotion Approach (primitive 101), the
collector resolves that selected candidate's observed stable object identity.
The target must still exist and be unconsumed. It becomes the next attention
incumbent; a changed identity resets retained ticks to one, an unchanged identity
keeps the existing count. Avoid, NoMove (103), failed, untargeted and unavailable
sources do not nominate. No object kind, food ID, nutrition or goal selects the
nomination. Execution-to-candidate primitive/target disagreement is an error.

The next normal attention pass still uses its unchanged salience calculation,
0.05 switch cost, observed roster and capacity. An unobserved object cannot be
retained. Genuine contact reservation and rotating exploration remain unchanged.
No action is forced, no contact is fabricated and no evidence is discarded.
This is not a new memory-query route or an increase in the hysteresis margin.

The optional native `approach_attention_feedback2325` decision receipt records
frame/organism/tick, selection and execution provenance, resolved identity,
before/after hysteresis and logical work. Twelve fixed receipt-field copies plus
performed lookups, predicates, visits and writes are charged in focal-target
work before the existing single cognitive debit and sealed outcome. A map lookup
is one semantic operation, not a claim about tree comparison count. The receipt
is omitted entirely on old identities. No runtime speed claim is made.

This is a manual research intervention, not acquired skill or a promoted brain.
Retained-row diagnostics showed both useful food-focus nominations and increased
hazard/competing-object focus. Live benefit is unproven. CPU qualification does
not establish GPU or full-game compatibility, recovery, meals or general safety.
