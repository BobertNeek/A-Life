# Experienced navigation map: explicit CPU research capability

This is an opt-in innate observed-map algorithm with acquired map state, not an inherited learned maze skill or a full-map oracle. CP20 stores a bounded graph from actual observed identities and actual movement. Passive caregiver transport is not recorded as traversed movement. Goal nomination follows actual policy choices; candidate biases enter the ordinary native sampler rather than forcing actions.

Modes 1 (ExploreBacktrack), 2 (GoalRoute), and 3 (validated ExploreBacktrack) are explicit persisted identities. Default absence and legacy CP19 behavior are unchanged. Mode 3 copies an alive mode-1 acquired graph and retains its existing body, neural/private history, policy, optimizer and sampling state. It removes one genuinely redundant full-map validation by passing a private owned validated token; external checkpoint and malformed-input validation remain. The semantic saving is the removed validation scan minus two token operations, not a measured runtime-speed claim. Modes 1 and 2 retain their old accounting.

## Evidence and limits

Focused native tests cover attachment, cold/next-step equality, row tampering, checkpoint validation, no fictitious passive-transport edges, death rejection, charged work, and mode-3 acquired preservation with scan-minus-two accounting. Three legacy configurations were separately compared for sixteen native steps each. GoalRoute mode 2 is source-qualified but has no demonstrated actual navigation benefit here. This is CPU research scope; no full-engine regression or GPU-gameplay validation is claimed.

Actual observed-map results are mixed. In the selected 2352 context, the map arm reached the meal at interval 117 versus 178 without the map, while using approximately 77.9% more work. In retained-world repeat 2357, optimized mode 3 reduced work approximately 4.285% but missed the meal, while mode 1 reached it at interval 652. Earlier route nodes had been evicted; this was revisiting a physical context, not proof of successful route recall. These are conditional individual comparisons, not general maze mastery, a population posterior, or a default-policy promotion.

Only source, hermetic synthetic tests and this documentation belong in the publication. No private checkpoints, trained policy arrays, optimizer state, biological traces or local artifacts are required by the tests. The existing repository fixture is used to construct a fresh synthetic organism, with explicit public g0/Inspect-valence calibration.
