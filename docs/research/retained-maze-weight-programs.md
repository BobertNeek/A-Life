# Opt-in CPU maze-weight program interface

This is a research interface, not a demonstrated maze-solving improvement or a default gameplay change. It preserves the genotype and acquired organism instead of replacing its brain.

## Identity and preservation

`fork_with_maze_program_for_research2346` creates an immutable CP18/capability3 to CP19 copy with an explicit maze-program capability and initially absent blocked history. It preserves body, world, memory, recurrent state, fast/lifetime weights, eligibility, sampling state, and founder optimizer state. Older readers reject CP19. Legacy absent capability has unchanged serialized representation and execution.

`calibrated_maze_program_copy2346` and `rebase_maze_program_policy2346` support a named, graph-validated module: fourteen recurrent coordinates and Approach/Inspect ActionCandidate readout coordinates. New weights must be finite and bounded by 16. Every other policy bit and Adam moment/age is preserved; the host policy digest changes explicitly. This is experimenter weight programming, not acquired learning or genetic inheritance. It is broader than a readout-only calibration.

## Truthful input and ordinary action selection

The new sensory input is the previous actual locomotion Blocked receipt, not an inferred obstacle map or player-care contact. Source identity, tick, sequence, frame and primitive are bound. It survives sleep and is consumed once on the next awake observation. Touch gain calibrates existing tactile lane7 (flat39); there is no sensory-width or genotype migration.

The interface adds only native STEP105 and body TURN604/605 opportunities. They compete through the ordinary sampler and remain subject to physics. The inherited two-head layout is unchanged: turns use representative orientation semantics, not a newly enabled independent orientation head. Object opportunity capacity changes from four to three, so an interface-only control is necessary.

Actual sensing, heading construction, history update, and existing attention/coverage operations contribute to the existing sole cognitive debit. Heading construction is a declared semantic tariff of 315 units for three descriptors across the three canonical construction passes, not a machine-instruction count or runtime speed claim.

A bounded neural prototype can transfer a blocked pulse through persistent recurrent phase into signed turn readouts. Synthetic public STEP and sleep operations in these tests are mechanics witnesses, not autonomous maze outcomes.

A retained CP18 control replays 256 intervals with exact ordered logits, sampled actions, full checkpoints at128/256, unchanged founder/Adam and unchanged source host. This is bounded compatibility evidence, not a full1024 or all-mode claim. An actual native CP19 copy is rejected by the old reader before any step.
