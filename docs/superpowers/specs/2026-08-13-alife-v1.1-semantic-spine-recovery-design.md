# A-Life v1.1 Semantic Spine Recovery Design

**Date:** 2026-08-13
**Status:** Approved direction; implementation planning pending user review
**Controlling architecture:** `docs/brain/ALife_Adaptive_Brain_Architecture_Spec_v1.1.md` after Phase 0 installs the supplied v1.1 Markdown
**Target:** One honest, playable, adaptive creature loop within one focused recovery sprint

## 1. Objective

Recover A-Life from two related forms of drift:

1. the implemented brain no longer supplies several capabilities required by the v1.1 controlling architecture; and
2. cognition, biology, body state, world state, lifecycle, persistence, and presentation still contain split authorities or incomplete production links.

The first recovery milestone is not a complete implementation of every v1.1 phase. It is one production creature whose real GPU cognition, authoritative body, biology, world consequences, learning, and rendered presentation form one causal game loop. The interfaces remain population-safe so later growth changes capacity and scheduling rather than authority.

## 2. Delivery posture

This is a 24-hour vertical recovery sprint, not a three-week infrastructure project.

The sprint prefers a complete but repairable production slice over a polished collection of disconnected subsystems. Repairable defects are acceptable when they are visible, bounded, and do not corrupt durable user data. Silent authority duplication, fake capability evidence, and architectural drift are not acceptable.

The sprint uses early checkpoints:

- By the first checkpoint, the canonical v1.1 authority and compliance matrix exist.
- By the second checkpoint, one organism has one authoritative biological record and its GPU brain receives state derived from it.
- By the third checkpoint, one real GPU-selected command changes the authoritative world and matching presentation entity.
- By the fourth checkpoint, one measured outcome changes a later cognitive state or decision through the sealed learning path.
- Work stops and the approach changes if a checkpoint cannot produce its named artifact promptly.

No broad refactor, population scaling, soak, release benchmark, or speculative abstraction may delay these checkpoints.

## 3. Sources of truth

The authority order is:

1. the user's goal: smart, fast, compute-efficient, evolvable, biology-inspired organisms;
2. v1.1 locked goals, capabilities, invariants, and semantic interfaces;
3. approved architecture decisions and mechanism substitutions;
4. implementation code, layouts, defaults, tests, and migration adapters.

Current code is migration evidence. It is not authority merely because it exists. A temporary limit, fixture, constant, data layout, hardware placement, brain class, or test expectation must not become a new architecture rule without an explicit decision.

Reference mechanisms may be replaced when the replacement preserves the required capability and invariants and produces equal or better capability per compute. Missing locked capabilities remain `NOT_STARTED`, `PARTIAL`, `BLOCKED`, or `DEFERRED`; they are never erased from status by implementation convenience.

## 4. Current state and protected work

The current committed source already contains more integration than the 2026-08-08 review recorded:

- a production GPU tick is scheduled;
- the world owns organism records, biology, lifecycle, actions, and outcomes;
- stable-ID presentation frames are published after successful ticks;
- existing creature transforms can consume authoritative positions;
- autonomous conception, birth, ageing, death, archive ordering, pause/speed scheduling, and runtime replacement helpers exist in source.

The remaining critical splits are:

- newborn GPU residents may be compiled from a global template instead of the newborn's inherited genome and phenotype;
- cognition retains mutable homeostasis and development state separate from the world organism record;
- the implemented brain still selects one semantic action instead of a factorized motor command bundle;
- concept topology and unresolved gaps are diagnostic, post-decision sidecars rather than bounded pre-decision cognitive context;
- prediction lacks a non-collapse target contract and action-sensitive self-supervised capability;
- structural growth, dendritic conjunction, integrated sleep, and cross-system cognitive work accounting remain incomplete;
- birth, retirement, body appearance, selection, following, inspection, and load are not yet one reliable presentation reconciliation path.

The existing dirty `AGENTS.md` and large uncommitted `production_voxel_renderer.rs` change are protected work. The renderer change must be reviewed by capability. Useful atomic-load work may be retained. Any regression of committed birth reconciliation must be repaired. The change is neither accepted wholesale nor discarded wholesale.

## 5. Authoritative organism model

`WorldOrganismRecord` is the single biological authority for:

- stable organism and world identity;
- inherited genome and expressed phenotype;
- body state and morphology-relevant traits;
- homeostasis, chemistry, endocrine state, fatigue, and sleep pressure;
- age, development, reproduction, lifecycle, birth, and death;
- archive and lineage identity.

GPU-resident state owns neural execution state:

- activations and recurrent state;
- foundation, genetic, lifetime, and fast weight banks;
- eligibility transactions;
- GPU-local sparse layouts and packed offsets;
- bounded neural diagnostics and decoder state.

The GPU brain receives an immutable, versioned cognitive input derived from the authoritative organism record each tick. It does not own a second mutable biological truth. A cache may exist only when it is digest-bound to the source record and replaced atomically; it cannot advance independently.

Birth uses the newborn's actual world record to compile and admit its GPU brain. Load uses the same record-derived admission route. There is no global-template shortcut for ordinary offspring.

## 6. Single-creature-first, population-safe shape

The first playable slice schedules one organism. This is a delivery simplification, not an architecture limit.

Population safety is retained through:

- stable `OrganismId` and `WorldEntityId` bindings;
- world-owned organism registries;
- fixed bounded frames and side buffers;
- class-bucketed GPU arenas with no active-loop resizing;
- batch-shaped prepare, dispatch, seal, commit, and presentation interfaces;
- per-organism sequence, eligibility, archive, and lifecycle identities.

Adding a second creature must require only admission, capacity, and scheduling. It must not require changing ownership, contracts, or the causal order.

## 7. Cognitive input and attention boundary

The first v1.1 cognitive contract is a bounded `CognitiveContextFrame` containing:

- body and interoceptive state derived from the authoritative organism record;
- cheap peripheral sensory summaries;
- a small bounded focal target set and attention budget identity;
- episodic `MemoryExpectancy`;
- active concept, causal relation, uncertainty, and unresolved-gap context;
- optional bounded semantic-prior context;
- prediction context and work-accounting identity.

The first slice may use a simple reference attention mechanism. The locked behavior is that creature state, memory, concepts, gaps, novelty, and budget can influence focal allocation without a host desirability score. Exact salience formulas, target counts, and CPU/GPU placement remain replaceable.

Topology and unresolved gaps may influence attention and neural context through this interface. They may not emit actions, targets, rewards, or hidden score biases.

## 8. Motor compatibility migration

The production semantic interface becomes a bounded factorized `MotorCommandBundle` with locomotion, orientation, manipulation, vocal, posture, and optional species-specific channels.

The first slice does not require a new physical implementation for every primitive. A temporary compatibility adapter maps a valid command bundle onto existing `ActionKind` world operations. The adapter is explicit, versioned, observable, and removable.

The adapter must preserve:

- every selected channel command in the decision record;
- one joint physical outcome;
- optional channel observations only when physically measurable;
- world authority over legality, execution, and consequences;
- no fabricated per-channel rewards.

The old single-candidate command remains a migration representation behind this adapter. It must not remain the controlling cognitive ABI.

## 9. Causal tick

The first production loop is:

1. Read the authoritative organism record and broad world state.
2. Build peripheral perception and bounded affordance hints without desirability scores.
3. Retrieve memory and concept/gap context.
4. Select focal targets within the organism's bounded budget.
5. Assemble the immutable cognitive context.
6. Run due GPU recurrent, predictive, and motor passes.
7. Decode a factorized motor bundle.
8. Let the world validate and execute the joint command.
9. Advance authoritative body, chemistry, ecology, development, and lifecycle once.
10. Measure the successor state and seal one `ExperiencePatch`.
11. Apply eligible neural learning, memory, concept/gap, homeostatic, structural-evidence, cost, and sleep-queue updates exactly once.
12. Publish an immutable stable-ID presentation snapshot.
13. Reconcile rendered body, labels, selection, follow camera, and inspectors.

Pipelining is permitted later only when sequence and identity remain exact.

## 10. Presentation and persistence

Presentation receives immutable per-organism snapshots keyed by both world and organism identity. A snapshot includes enough authoritative state to project:

- position and orientation;
- lifecycle presence and visibility;
- phenotype/body appearance inputs;
- health, injury, sleep, age, and reproductive state needed by current visuals;
- selected motor channels and measured outcome summaries for animation and inspection.

The reconciler performs spawn, update, and retirement from these snapshots. A newborn body is built from its phenotype, never by copying an arbitrary creature. Every root is bound into the same stable-ID map used by selection, following, labels, inspectors, and retirement.

Pause and speed govern authoritative ticks. Save checkpoints the same world, organisms, cognition, and presentation identities. Load prepares an entire candidate runtime and scene, then atomically replaces them or leaves all current state unchanged.

## 11. Verification budget

The sprint permits only the smallest checks that prove its semantic boundaries:

1. **Authoritative organism test:** newborn and loaded cognitive residents derive genome, phenotype, and interoception from the matching world record.
2. **Presentation reconciliation test:** one snapshot can spawn, update, select, inspect, and retire the matching creature without template cloning or ghosts.
3. **Production GPU causal test:** one real GPU-selected action changes the authoritative organism/world and the matching rendered entity through the installed production schedule. The test must not manually inject the presentation frame.
4. **Short learning test:** two grounded contexts produce a measured outcome, and the sealed outcome changes a later memory, neural state, or decision in the intended direction.
5. **Atomic load test:** success replaces runtime, world, scene, controls, and focus together; rejection preserves all of them.

Iteration uses one RED and one focused GREEN command per boundary. A final narrow integration check runs only after the slice is stable. Broad workspace tests, full GPU matrices, EI corpora, soaks, scale benchmarks, and redundant test variants are outside this milestone.

Tests that freeze private names, fixed delays, exact internal stage vectors, candidate indices, N2048 reference layouts, or current data structures are retained only as explicitly versioned compatibility contracts. Otherwise they are rewritten around capability or removed.

## 12. Cleanup and replacement rule

Competing or apparently unused systems may be removed when all of these are true:

1. their intended capability is named;
2. the surviving authority and mechanism are named;
3. any unique useful behavior or durable data is migrated;
4. no live caller or deferred v1.1 capability depends on them;
5. the focused causal gate passes without them;
6. the deletion is independently reviewable and recoverable through Git.

Scaffolding, duplicate caches, obsolete adapters, source-text tests, and dead whole-body policy paths are expendable. Deferred attention, prediction, concept, gap, structural, dendritic, sleep, development, and evolution capabilities are not expendable merely because their current implementation is incomplete.

## 13. Explicit non-goals for the first slice

The first sprint does not certify:

- population scale;
- EI1 promotion;
- 500 N2048 agents;
- final attention quality;
- mature concept induction;
- non-collapsing prediction quality;
- useful synaptogenesis or dendritic computation;
- complete sleep consolidation;
- final cognitive economics;
- public alpha readiness.

These remain visible in the compliance matrix and follow v1.1 dependency order after the semantic spine works.

## 14. Completion gate

The first recovery milestone is complete only when one organism, through the production schedule:

- perceives authoritative world and body state;
- receives bounded memory and concept/gap context;
- selects a real GPU motor decision;
- changes the authoritative world and biology;
- seals and consumes the exact causal outcome;
- exposes a later learning effect;
- updates the same rendered creature and inspector by stable identity;
- survives pause/save/load without creating another authority;
- can be joined by another organism without changing the semantic interfaces.

Source presence, serializers, synthetic frames, direct fixture calls, static screenshots, and large test counts do not satisfy this gate.
