# Policy-weight comparison identity repair

Mode 2; separate-agent review class R2. This is measurement correctness, not
learning evidence or a change to organism execution. Requirements traced:
AOA-INV-010, AOA-CTX-001, AOA-CTX-003 and AOA-PRIOR-001.

## Problem and contract

The existing complete world identity includes every organism genome and its
foundation policy. Two different policies therefore cannot satisfy that identity
gate even when their recorded input contexts match.

Keep that canonical identity byte-compatible. Add a distinct versioned comparison
domain binding one designated subject. Validate its actual asset and record
first, then project exactly `genome.n2048_foundation_candidate.weights`, its
asset-level `digest`, and `manifest.weight_asset.digest`. Retain all other fields,
except rederive the subject's genetics/development content digest from the
projected genome and unchanged phenotype in a comparison-specific domain. Keep
that reference's ownership, schema, revision and causal tick and the entire
remaining graph. Retain the full non-treatment state,
including weight count, schema, graph/ABI identities, training stage, complete
promotion provenance, genotype, phenotype, physiology, lifecycle, archive state,
and every other organism's complete policy. Never admit a projected asset.

Native pilot receipts bind this projection to the actual canonical policy file
and running executable with SHA-256. The read-only comparator requires externally
declared policy/executable hashes and equal world, physical setup, sampler,
teacher/cue provenance, first sensory/physiology frame and candidate/motor masks.
Candidate scores and later outcomes are outputs, not comparison inputs. Unknown
or missing identity schemas cannot fall back to historical context hashes.

## Scope and verification

1. Share the full world traversal; preserve ordinary canonical callers and bytes.
2. Produce new evidence before GPU creation and consume it in the committed CLI.
3. Test valid policy-only changes, retained manifest/provenance, other organisms,
   wrong/missing subjects and malformed assets. Reject real world/physiology,
   sensory, mask, setup, sampler, cue and executable-provenance differences.
4. Keep existing canonical world regressions. Run focused native CPU tests in
   Linux/Windows CI, lightweight Python tests locally, and exact-head CI before
   merging. No local neural execution or GPU learning rerun is required.

The completed PR95 qualification, source policy7400, original seed accounting and
all failed qualification receipts are immutable. The decision remains
**do not adopt**. No old artifact is newly qualified, no adoption threshold is
relaxed, and no curriculum mechanic is added. Future experiments require their
own predeclared identity version and all behavioral adoption gates.
