# Gullglass bladderlace

Seven discontinuous wet knuckles of the real shore carry 35 folded fans. Each fan is a static authored prop, not an organism/food/brain change. It starts from a low irregular grip, lays three-dimensional curled blades along gravity projected onto the original face, forks into paired leaves, and bears asymmetrical little old-gold floats. The three forms have different leaf count, ages and proportions; each has near/middle meshes. The exact native contact normal, direction and metres are in the root ledger. Existing small shell casts were avoided to leave legible gaps rather than cover them with unrelated decoration.
