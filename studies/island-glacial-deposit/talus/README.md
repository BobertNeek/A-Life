The close frame shows the original horizontal rings disappear, but downhill fragments still hang over the ground. At guardian height this shape change alone is minor. **Do not install this unseated form**. The V1 physical generator emits boxes for tree trunks and Boulder*/Cliff but not Scree; the engine’s solid-prop rendering-distance category is not a physics collider. Per-piece seating on actual terrain is therefore a legitimate separate art experiment, not a move to the saved obstruction map. The neighbouring A/B/C, daylight, terrain and other prop placements were identical in each photographic pair. 134 original instances use this mesh. No ground-proof or FPS claim can be obtained from a Blender still.
