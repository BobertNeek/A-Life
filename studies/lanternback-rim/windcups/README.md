# Windcups · a near-field morphology proposal

The two independently held Lanternback creature views reveal a visual problem at the plant itself: the crown of the original pennon reads as three upward triangle flags, and all its basal leaves read as sharp flat paper. Keep it strange and friendly, readable at a glance without lights, neon, UI or labels. Real valve edges, maturity and the air between flowering stalks should carry its silhouette.

The editable deterministic specimen script grows three compact forms, each roughly the original plant height. Their deeply channelled strap leaves have rubbed tips and two ages, and their four-valve capsules shoulder into a fluted green collar instead of floating as separate planes. Each fruit varies from a closed garnet bud to a tilted pale papery head with a visible warm staminal crown. The middle/far morphology remains original. planting.py starts with the exact old heath instance stream, exchanging only the seven plants physically inside the study's selected patch and keeping every selected ground root, original decorative model variant, quaternion and scale. These are decorative mesh variants only, never a new species, game prop, script modifying the actual map, fruit resource, medical/biological effect or physics object.

Source workflow: run specimen.py OUT; run planting.py HELD-RIM/wind-heath.glb OUT/pennon-windcups.glb PREPARED-STUDY. The combined GLB carries the whole prior instance transform field just for photographic substitution; never install it over a live native file. For an exact locked comparison use the final Pennon Drift ground as control, and change only the seven near crowns. Bring forward the identical camera/lenses, soil pigment, sky, foliage and stone, not a new photographic mood. The model generator and registered positions are saved independently, so a later director can accept or reject the close design without unwinding any other work.
